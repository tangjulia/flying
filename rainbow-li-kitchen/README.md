# Rainbow's Table · 私房食谱

一个无需构建工具的单页菜谱网页，打开 `index.html` 即可使用。页面以中餐为主，另含少量日料和西餐；每道菜的配方与步骤均为简明整理，菜谱卡片内提供原始参考来源，部分菜谱可直接播放视频或打开来源页观看。

## 功能

- 按中餐、日料、西餐筛选，搜索菜名并切换到收藏夹。
- 收藏保存在当前浏览器的本地存储中。换浏览器或清理浏览器数据后，收藏不会自动同步。
- 菜谱详情里可调整份数、勾选食材、阅读步骤。
- 可同时启动多个倒计时；步骤旁的小计时按钮可直接启动对应时长。
- 手机窄屏布局自适应。

## 发布到 GitHub Pages

将整个 `rainbow-li-kitchen` 文件夹内容上传到仓库根目录或 `docs` 目录，再在仓库设置的 Pages 选项中选择对应发布分支和目录。网页没有构建步骤；图片、字体和视频需要网络连接。

## 内容与图片来源

菜谱卡片链接到参考来源页面；封面图来自 Unsplash，网页底部列有图片署名。视频采用 YouTube 嵌入或原菜谱页链接，具体播放可用性取决于所在网络与平台地区限制。
